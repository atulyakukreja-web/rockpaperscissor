# 🪨 Rock Paper Scissors — Arena

A fast, interactive **Rock Paper Scissors** game built with **HTML, CSS & JavaScript**. Play against the computer, track your score, and build winning streaks in a neon-themed UI.

### ✨ Features

* 🪨📄✂️ Player vs. Computer
* ⚡ Animated round reveals
* 📊 Live score & streak tracking
* 🔄 One-click reset
* 📱 Fully responsive
* ♿ Accessible & reduced-motion friendly
* 🎨 Dark neon UI

### 🛠️ Tech Stack

**HTML5 • CSS3 • Vanilla JavaScript**

### 🚀 Run Locally

```bash
git clone https://github.com/your-username/rock-paper-scissors-arena.git
cd rock-paper-scissors-arena
```

Then open `index.html` in your browser. No dependencies or build step required.
